# Gold Appraiser — Ornament Catalogue

A rebuilt, single-scroll, responsive ornament reference app using plain HTML, CSS and JavaScript.

## Included
- 100 ornament catalogue entries with English and Telugu names
- Bundled illustrative ornament images in `images/ornaments/`
- Category dropdown filter with per-category counts
- Search across English name, Telugu name, category and description
- Reset filters / clear search
- Modern indigo, lavender and blush design
- Works offline when opened from the extracted folder; no external JS dependencies

## Run
Extract the ZIP and open `index.html` in a browser. For best local testing, use VS Code Live Server. No Python or build step is required.

## Notes
Images are illustrative references, not real photographs. Names and styles may vary by region. They do not establish purity, weight or value.
